# 🤖 AI Data Analyst

## 📌 Overview
This project simulates a data analyst.

Users ask questions about data,
and the system converts them into SQL queries.

## 🚀 Features
- Question → SQL
- Data analysis
- Instant results

## 🧠 Example Questions
- What is total revenue?
- Show revenue by category
- What is the trend?

## 🛠 Tech Stack
- Python
- SQL
- Streamlit
